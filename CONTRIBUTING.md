# Nouveau Peuple, Nouvelle Constitution - Developer Invitation

## Welcome Developers! 🚀

We're excited to invite talented developers to join our development team and contribute to the **Nouveau Peuple, Nouvelle Constitution**.

### About the Project

A citizen platform for co-writing the 6th French Republic constitution, featuring constitutional workshops, participatory RIC (Citizens' Initiative Referendum), and a democratic laboratory for experimenting with different democratic systems.

**Repository:** [Fraxadel/actionpopulaire.fr](https://github.com/Fraxadel/actionpopulaire.fr)

### How to Get Involved

We welcome contributions from developers of all skill levels! Here's how you can get started:

#### 1. Fork & Clone
```bash
git clone https://github.com/Fraxadel/actionpopulaire.fr.git
cd actionpopulaire.fr
```

#### 2. Set Up Development Environment
- Review the README.md for setup instructions
- Install dependencies
- Run the project locally

#### 3. Find Issues to Work On
- Browse our [Issues](https://github.com/Fraxadel/actionpopulaire.fr/issues) to find tasks
- Look for issues labeled `good first issue` or `help wanted`
- Comment on issues you'd like to work on

#### 4. Submit Your Contributions
- Create a feature branch: `git checkout -b feature/your-feature-name`
- Make your changes and commit them
- Push your branch and create a Pull Request
- Our team will review and provide feedback

### Development Guidelines

- Follow the existing code style and conventions
- Write clear, descriptive commit messages
- Include tests for new features when applicable
- Update documentation as needed
- Be respectful and collaborative in all interactions
